Thien and Lin extended SHamir's idea and proposed an SIS scheme based on the $(r, n)$ threshold scheme in which each generated shadow image $1/r$ the size of the secret image. A limitation is that pixel values must be truncated down to 250. They also apply a permutation step on the original image before performing sharing process to hide the correlation among neighboring pixels.

The proposed method is to change the prime number $251$ to $257$. The only condition we need to deal with is the case of $256$.
By using the prime $257$, the preprocessing of the truncation is no longer necessary. Furthermore, processing very light images (with high and hence probably greater than 250 pixel values) is now possible.
Secondly, a simple and fast encryption using table lookup technique is used to replace the permutation process.

##### Encoding an image O to $n$ shadow images
1. Take the XOR operation to a pre-defined random table R and O. R is generated by a pseudo random number generator in advance. Q denotes the randomized image.
2. Set the current processing section number $j$ to 1.
3. Sequentially take $r$ non-processed pixels, say $a_0, a_1, ..., a_{r-1}$, of Q to form a sharing section $j$. WLOG, let the current processing section be the $j-$th section of the image, and create a polynomial of degree $r-1$ as follows:
   $f_j(x)=(a_0 + a_1x + ... + a_{r-1}x^{r-1}) \bmod 257$
4. Generate the $n$ shadow pixels by evaluating the polynomial in $1...n$.
5. If $f_j(x)=256$, let the first non-zero pixel of $\{a_0, a_1, a_2, ..., a_{r-1}\}$ be decreased by 1, say $a_0=a_0-1$ and go to step 4.
6. Sequentially assign pixels generated in step 4 to the $j$th pixel of the $n$ shadow images.
7. Increase $j$ by 1.
8. Repeat steps 3 to 7 until all pixels of $Q$ are processed.\

Reconstruction is also easy:
1. Set the current processing section $j$ to $1$.
2. Take a non-processed pixel of position $j$ from each of the $r$ shadow images.
3. Use these $r$ pixels $f_j(1), f_j(2), ..., f_j(r)$ and Lagrange's interpolation to solve the coefficients $a_0, a_1, a_2, ..., a_{r-1}$. These will be exactly the $r$ pixel values of the $j$-th section in $Q$.
4. Increase $j$ by $1$.
5. Repeat steps 2 to 4 until all pixels of the shadow images are processed.
6. Apply the XOR operation to the predefined random image R and Q to get the secret image O.
